# Environment Text Descriptors

Extracted from the 16 environment reference images. Use these as inline text in prompts instead of passing env images as —image refs. This eliminates ref bleeding while giving Seedance precise environment guidance.

**Usage**: Drop the descriptor text directly into the Scene: section or CUT descriptions in place of vague environment labels. Be specific about the texture, light colour, atmospheric density, and scale details listed here.
