# 10 — Creative Direction (The Brain)

**Role:** The concept-generation engine. Turns BRIEF + reference analyses into ONE committed, original creative concept with a structural tension, a signature moment, and a full art-direction stance. This file is where "the user sends a sentence, the system decides everything" actually happens.
**Phase:** 2 (CONCEPT) — the first creative act, before any code or design.
**Inputs:** BRIEF.md, MODELING-SPEC.md, PLATE-SHEET.md (if any).
**Outputs:** `_process/CONCEPT.md`.
**Upstream:** `01`–`03` · **Downstream:** `11`–`14`, and through them everything.

---

## What a concept IS

Not a style. Not "clean and modern". A concept is **one idea about the subject that reorganizes
everything** — IA, palette, motion, copy, the works. Test: you can state it in one sentence and
every design question ("what does the 404 look like?") has an obvious answer under it.

Award-tier sites hang on **one structural tension** found inside the subject itself
(landonorris.com: ON TRACK / OFF TRACK drives IA, palette chapters, motion). Find the true tension:
craft↔chaos, tiny↔cosmic, ancient↔synthetic, still↔explosive, indoors↔wild. One axis, everything
obeys it.

## The procedure

### 1. Gather raw material (30 min)
From BRIEF's brand-DNA + subject research: 5 facts, 3 category clichés (to break), the essence-word,
the object's physical personality, the plate's mood (if any). Write them as a scratch list.

### 2. Generate 5 divergent directions — forced lenses
Generate one concept per lens. The lenses force distance between options (five variations of one
idea = failure). For each: name (2 words), one-sentence idea, the tension, the signature moment,
first palette instinct, one risk.

| Lens | Question it forces |
|---|---|
| **Scale-shift** | What if the object were a planet? Or you were 2mm tall beside it? (macro-world, landscape-of-the-product) |
| **World-building** | What world does this object come from? Build THAT place; the site is a visit. |
| **Material poetry** | Follow the material itself (glass, steam, fabric) as protagonist; the object is its destination. |
| **Kinetic language** | Typography/graphic system IS the experience; the object punctuates it. |
| **Documentary macro** | Truth-telling: process, origin, numbers — shot like a nature film, drama from reality. |

(Swap a lens freely if the subject begs for another: ritual, game, museum, laboratory…)

### 3. Score and commit

Score each direction 1–5 on: **Originality** (would a heavy Awwwards browser say "seen it"? — see
anti-clone below) · **Subject-fit** (does it amplify THIS subject or would it fit anything?) ·
**Narrative potential** (does it give 5–7 scroll beats? see `11`) · **Feasibility** (can Phases 3–5
deliver it at quality within budgets?) · **Signature moment strength** (is there one nameable thing
people will describe to a friend?).

Commit to the highest total — but a 1 in Originality or Feasibility disqualifies regardless.
It is allowed (encouraged) to graft one strong organ from a losing direction onto the winner.

### 4. The anti-clone gate (hard, mandatory)

The reference sites are a LEVEL, not a LOOK (doctrine law 2; the user's explicit instruction).
Before committing, check the concept against:

- The three reference sites: does it share a core idea, mascot strategy, palette family + layout
  combo, or signature moment with any of them? → regenerate that element.
- The current award-site zeitgeist (the "seen-it" test): giant-hero-object-spins-on-scroll alone is
  not a concept; neither is dark-site-with-blob-shader. If the one-line pitch could caption an
  existing famous site, sharpen until it can't.
- Cliché ban-list for the category (from step 1): the concept must break at least one category code
  deliberately.

### 5. Derive the concept constitution

Once committed, write the constitution — the ten decisions every downstream file obeys:

1. Concept sentence (the idea)
2. Structural tension (the axis)
3. Signature moment (one, nameable, described in two sentences)
4. Narrative logline → seeds `11`
5. Palette stance (e.g. "sun-bleached field + one shock of green") → `12` derives tokens
6. Type personality (loud/quiet, condensed/wide, mono accents?) → `13`
7. Motion personality (elastic-playful / cinematic-heavy / brutal-instant) + the object's physics → `32`
8. Voice (first-person? deadpan? reverent?) → `14`
9. Environment stance (recreate plate exactly / invent: which archetype family) → `25`
10. Delight placement plan (loader, 404, footer toy, hidden egg) → `33`,`34`

## Case C (no references at all)

Extract brand DNA from the sentence + web research instead of images; the object (if one is needed)
is DESIGNED here (sketch its proportions/materials in words → a MODELING-SPEC is still written via
`02`'s format, sourced from imagination + brand logic instead of pixels). Lenses and gates unchanged.

## Style-reference case

If the user sent a style reference ("like this vibe"), extract ONLY: mood adjectives, palette
family, energy level. Then run the normal procedure. Layout, concept, and signature moment still
must be original — verify at the anti-clone gate.
