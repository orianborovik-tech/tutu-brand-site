# תל אביב 3D — כל העיר בדפדפן

מודל תלת־ממדי אינטראקטיבי של כל תל אביב–יפו (וטבעת קו הרקיע: בורסה ר״ג, גבעתיים, בת ים),
בנוי מנתוני OpenStreetMap אמיתיים. ללא מפתחות API, ללא רשת — הכל בקובץ.

## מה בפנים

- **60,768 בניינים** עם גבהים/קומות אמיתיים, כולל building:part — עזריאלי עגול/משולש/מרובע,
  מגדל שרונה, מגדלי הבורסה; שמות בעברית ל־2,392 מבנים (לחיצה על בניין → מידע).
- **~3,500 ק״מ דרכים** ב־9 מחלקות, גשרי איילון מוגבהים, מסילות רכבת.
- **ים** סגור מקו החוף האמיתי + קצף גלים, חופים, הירקון, בריכות, פארקים, מגרשים, נמלים.
- **~97,000 עצים** (997 ממופים ב־OSM + שתילה פרוצדורלית דטרמיניסטית בפארקים ושדרות),
  דקלים לאורך הטיילת.
- **מיקרו־פרטים**: דודי שמש וקולטים על גגות מגורים, מזגנים על גגות מסחר, פנסי רחוב
  (+341 ממופים), 1,920 רמזורים אמיתיים, סירות במרינה ובנמל יפו, נצנצי אזהרה על מגדלים.
- **תנועה חיה**: ~1,500 מכוניות ואוטובוסים על רשת הכבישים, פנסים קדמיים/אחוריים בלילה.
- **תאורה מלאה לפי שעה**: יום / שקיעה / לילה + סליידר רציף; חלונות נדלקים פרוצדורלית,
  הילות פנסים, כוכבים.
- ממשק עברי RTL, טיסה חופשית (עכבר/מקלדת/מגע), קפיצה לאתרים, סיור מודרך.

## הרצה

```bash
cd tel-aviv-3d
python3 -m http.server 8123   # או כל שרת סטטי
# → http://localhost:8123
```

או לבנות קובץ יחיד עצמאי (נפתח גם ב-file://):

```bash
node scripts/build-artifact.mjs out.html
```

## בנייה מחדש

```bash
npm install
npm run build        # esbuild → bundle.js
```

### עדכון הנתונים מ־OSM

```bash
pip install osmium
curl -o israel.osm.pbf https://download.openstreetmap.fr/extracts/asia/israel_and_palestine-latest.osm.pbf
python3 scripts/extract_telaviv.py extract israel.osm.pbf work
python3 scripts/extract_telaviv.py pack work data
```

## ארכיטקטורה

`scripts/extract_telaviv.py` סורק את ה־PBF פעם אחת (pyosmium FileProcessor + פילטרים ב־C++),
אורז לפורמט בינארי `TLV1` (קואורדינטות דצימטר בדלתא Int16, שולחנות שמות/צבעים) → gzip →
base64 בתוך JS (‏2.7MB). בדפדפן: פענוח ב־DecompressionStream, אקסטרוזיה עם earcut
(כולל חצרות/חורים), אריחי 1.5 ק״מ עם frustum culling, שיידרים ידניים עם נורמלים
מ־derivatives, חלונות פרוצדורליים, log-depth לכל קנה המידה, ואינסטנסינג לכל השאר.
