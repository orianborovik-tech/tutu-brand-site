# Tutu Live — סטודיו שידור חי 🎥🎙️

אפליקציית ווב שרצה כולה בדפדפן: **וידאו חי ורציף מהמצלמה** (זרם אמיתי, לא צילומי תמונות),
מיקרופון עם מד עוצמה בזמן אמת, זיהוי דיבור לעברית (ועוד שפות) והקראה קולית.

## מה יש בפנים

- 📹 **שידור וידאו חי** — זרם רציף מהמצלמה ב־720p, עם טיימר שידור ומחוון LIVE
- 🎙️ **מיקרופון חי** — ויזואליזציה של עוצמת הקול בזמן אמת (אקולייזר)
- 🗣️ **דיבור ← טקסט** — תמלול חי של מה שאתם אומרים (עברית, אנגלית, רוסית, ערבית ועוד)
- 🔊 **טקסט ← דיבור** — כתבו והמחשב יקריא בקול
- 🪞 מראה, כיבוי/השתקה, החלפת מצלמה ומיקרופון, מסך מלא, חלון צף (PiP)
- ⏺ **הקלטת השידור** והורדה כקובץ וידאו (webm)

הכל מקומי — שום וידאו או שמע לא נשלח לשרת.

## איך מריצים

מצלמה ומיקרופון עובדים רק תחת HTTPS או `localhost`, לכן מרימים שרת מקומי קטן:

```bash
# מתוך תיקיית הריפו:
python3 -m http.server 8000
```

ואז גולשים אל: <http://localhost:8000/live-studio/>

לוחצים **„התחל שידור"**, מאשרים לדפדפן גישה למצלמה ולמיקרופון — וזהו.

## דרישות

- דפדפן עדכני: Chrome / Edge (מומלץ — כולל זיהוי דיבור), Firefox / Safari (ללא זיהוי דיבור)
- זיהוי הדיבור (Web Speech API) דורש חיבור לאינטרנט בחלק מהדפדפנים
